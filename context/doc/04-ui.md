# UI要素の名称資料（fivepoint）

`src/fivepoint.html` に基づくUI要素の名称と識別子一覧です。番号は `context/doc/04-ui.svg` の注釈番号と対応しています。

1. ヘッダー左セクション: `header .left` … 左側の操作エリア（ボタン群）
2. フォルダ選択ボタン: `#pickDirBtn` … 画像フォルダを選択
3. 再読み込みボタン: `#refreshBtn` … 一覧再読込と非JPGの自動変換
4. 総数ラベル: `#totalCount` … ファイル総数（例: 12枚）
5. ヘッダー中央セクション: `header .center` … 評価とファイル名表示エリア
6. 評価セレクト: `#ratingSelect` … 0〜5 の評価を選択
7. ファイル名ラベル: `#fileLabel` … 現在のファイル名表示
8. ヘッダー右セクション: `header .right` … 初期化操作エリア（ボタン群）
9. 通番のみ初期化ボタン: `#seqInitBtn` … 評価を保持し通番のみ 0-00000 から振り直し
10. 全て初期化ボタン: `#initBtn` … 0-00000.jpg から通番で完全初期化
11. ビューア: `#viewer` … 画像表示コンテナ（クリックで実サイズ切替／ドラッグでパン）
12. メイン画像: `#mainImage` … 現在表示中の画像
13. サイドバー: `aside.sidebar` … パネル／サムネイル／ドロップ領域から成る右側エリア
14. 操作ヒントパネル: `.panel .hint` … 追加や採番の説明テキスト
15. サムネイル一覧: `#thumbList` … サムネイルアイテム（`.thumb`）のコンテナ
16. ドロップゾーン: `#dropzone` … 画像をドラッグ＆ドロップで通番コピー追加
17. 進捗オーバーレイ: `#progressOverlay` … 変換・採番等処理中のモーダルオーバーレイ
18. 進捗テキスト: `#progressText` … 「現在／総数」の進捗表示（オーバーレイ内）

## 備考
- ボタン配色クラス: `.BtnStart`（開始系）、`.BtnRefresh`（更新系）、`.BtnSeqInit`（通番初期化）、`.BtnInitAll`（全初期化）
- ビューア状態クラス: `.viewer--actual`（実サイズ・パン可能）、`.viewer--dragging`（ドラッグ中）
- サムネイル項目: `.thumb`（クリックで選択）、`.active`（選択状態）、内部に `img` と `.meta`
- ドロップ中ハイライト: `.dz.dragover`
- キーボード操作: 数字キー `0`〜`5` で評価変更
