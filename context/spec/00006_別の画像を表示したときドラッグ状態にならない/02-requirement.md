# 要件定義: 別の画像を表示したときドラッグ状態にならない

## 背景/目的
- 実サイズ表示で画像をドラッグ移動中に別の画像へ切り替えると、切り替え後の画像が最初のクリックでドラッグ状態にならない不具合がある。
- 連続した画像閲覧操作を途切れさせないため、切り替え直後でもドラッグ操作を即座に行えるようにする。

## スコープ
- 対象: 実サイズ表示モードにおける画像切替直後のドラッグ開始処理。
- 非対象: 実サイズ表示以外の表示モードやドラッグ以外の操作。

## 機能要件
- 画像切替後、最初のマウスダウン操作で新しい画像がドラッグ状態になること。
- 追加のクリックを必要とせずドラッグ移動できること。
- 既存のドラッグ移動速度や範囲などの挙動を変えないこと。

## 非機能/品質要件
- 切替やドラッグ操作に遅延やカクつきが発生しないこと。
- 画像切替・ズーム・評価変更・ドラッグ&ドロップ追加など他機能に影響しないこと。
- コンソールエラーが発生しないこと。

## 受け入れ条件（受入テスト観点）
- 実サイズ表示で画像Aをドラッグ中にサムネイルから画像Bへ切り替える。
  - 画像B表示後、最初のマウスドラッグ操作で画像Bが移動する。
  - 追加のクリックを要求されない。
- 他操作（ズーム、評価変更、フォルダ切替）が従来通り機能する。

## 制約/補足
- 画像切替時にドラッグ関連の状態を適切にリセットすること。
- 実装は既存のコーディング規約（クラスUpperPascalCase、メソッドLowerCamelCase、定数UpperSnakeCase、変数LowerSnakeCase）に従うこと。
