## 背景
- テーマにダークモードとライトモードを切り替える機能を追加したいという要望がある。

## 期待する動作
- ダークモードは現状の配色を維持したまま利用できること。
- ライトモードでは作業の気分が明るくなるような配色を採用すること。
- テーマ切り替えボタンの色味は現在のまま変更しないこと。

## 対象ファイル名
- src/fivepoint.html

## 対象メソッド
- `:root` に定義された CSS カスタムプロパティ（ダークテーマの基調色）
- ヘッダー・ビューア・サイドバーを構成する HTML 要素とそれらに紐づくスタイル定義
- テーマ切り替えに関連する JavaScript 処理は未実装

- レイアウトはヘッダーとメイン領域をグリッドで構成し、メイン領域内に画像ビューアとサイドバーを左右分割して配置している。ヘッダー内のボタン群（フォルダ選択・再読み込み・初期化など）の外観はカスタムプロパティとクラスごとのスタイルで決まり、現在のダーク配色を前提としている。【F:src/fivepoint.html†L23-L148】【F:src/fivepoint.html†L152-L213】
