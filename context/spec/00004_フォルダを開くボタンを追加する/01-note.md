# フォルダを開くボタンを追加する(取り下げ)
再読み込みボタンの右隣りにフォルダを開くボタンを追加する
ボタンをクリックすると、フォルダ選択ボタンで選択中のフォルダパスをOSのエクスプローラーで開くこと
ボタンの大きさは文字の長さに合わせる(再読みボタンのサイズ設定と同じ仕組み)
色味は既存のボタンや「spec/00001_ボタンの色を変更したい」で決めたルールで検討すること
フォルダが選択されてない場合はクリックしても何も起きないこと(再読みボタンと同じでOK)

# フォルダを開くボタンを追加するの検討結果
OSのエクスプローラーを直接起動する標準APIは存在しないため、以下を検討する

# 選択中のフォルダパスをクリップボードにコピーしたい
再読み込みボタンの右隣りに選択中のフォルダパスをクリップボードにコピーするボタンを追加
ボタンの大きさは文字ではなくアイコンで示したい
色味は既存のボタンや「spec/00001_ボタンの色を変更したい」で決めたルールで検討すること
フォルダが選択されてない場合は「フォルダが選択されてません」とポップアップ表示すること

# 選択中のフォルダパスをクリップボードにコピーしたいの検討結果
絶対パスはブラウザからは取得できないため、対応自体取り下げるものとする
