# 要件定義

## 概要
ビューアとサイドバーの左右配置を入れ替え、ビューアを右、サイドバーを左にレイアウトする。

## 機能要件
- サイドバーを左側、ビューアを右側に配置すること。
- ビューア領域とサイドバーのサイズは現状を維持すること。
  - 例: 通常時はサイドバー幅を約 360px、狭幅時は約 280px、ビューアは残り幅。
- レイアウト以外の挙動（クリックで実寸表示、ドラッグ、サムネイル選択、評価変更、ヘッダー操作など）に影響を与えないこと。
- 既存のクラス名・ID・イベントハンドラは原則変更しないこと（やむを得ず変更する場合も既存テスト・既存APIに影響を与えないこと）。
- 既存のテストが全て成功すること。

## 範囲外（非対象）
- 新機能追加や操作フローの変更。
- ビューア／サイドバーのサイズ変更（現状のサイズ感を維持）。
- ドキュメント（UI図など）の更新は本要件の範囲外（別タスクで実施可）。
