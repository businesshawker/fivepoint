# タスクリスト: 00007 ビューアとサイドバーの位置を逆にする

## 実装タスク
- [ ] CSS 変更: `src/fivepoint.html` の `main` を `grid-template-columns: 360px 1fr` に変更する。
- [ ] CSS 変更: `@media (max-width: 1000px)` 内の `main` を `grid-template-columns: 280px 1fr` に変更する。
- [ ] CSS 追加: `.sidebar { grid-column: 1; }` を追加する。
- [ ] CSS 追加: `.viewer  { grid-column: 2; }` を追加する。
- [ ] viewerとsidebarのHTMLを入れ替えること(sidebarの方を先に記述する)

## リグレッション考慮（非変更の明示確認）
- [ ] `.viewer`, `.viewer--actual`, `.viewer--dragging`, `.sidebar` の既存スタイルに変更が入っていないこと。
- [ ] ビューアの実寸トグル（クリック）とドラッグ挙動が従来通りであること。
- [ ] サムネイル選択、評価変更、各操作ボタンの挙動が従来通りであること。

## テスト（自動）
- [ ] 既存テストを実行し、全て成功すること。
  - コマンド例: `npm test`

## テスト（手動・受け入れテスト）
- レイアウト
  - [ ] 画面幅 > 1000px で、サイドバーが左（約360px）、ビューアが右（残り幅）に表示される。
  - [ ] 画面幅 <= 1000px で、サイドバーが左（約280px）、ビューアが右（残り幅）に表示される。
  - [ ] DOM 順は従来通りでも視覚的な左右が入れ替わっている（`.sidebar` が列1、`.viewer` が列2）。
- ビューア挙動
  - [ ] ビューア画像をクリックすると実寸表示へトグルし、再クリックで元に戻る。
  - [ ] 実寸時にのみドラッグでき、枠外に出ないように移動範囲が制限される。
  - [ ] 画像がビューアより小さい場合はドラッグできない。
  - [ ] 画像切替時にドラッグ状態が適切にリセットされる（`viewer--dragging` が残留しない）。
- サイドバー挙動
  - [ ] サムネイル一覧がスクロール可能で、クリックで該当画像がビューアに表示される。
  - [ ] 選択中サムネイルのハイライトやフォーカス挙動が従来通りである。
- 評価・リネーム関連
  - [ ] 評価変更でファイル名が所定形式に変わり、一覧がソートされる。
  - [ ] 変更後も現在選択が維持され、表示が途切れない。
